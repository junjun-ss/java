# Main Exam JSON

시험에서 JSON 파일 읽기, JSON 문자열 파싱, Gson 변환이 나오면 이 패키지를 먼저 봅니다.

사용 라이브러리: Google Gson `2.8.6`

| 파일 | 용도 |
| --- | --- |
| `JsonFileReadExample.java` | `person.json`, `people.json` 파일을 읽어서 POJO/List로 변환 |
| `GsonParsingExample.java` | JSON 문자열, JSON 배열, nested JSON을 Gson으로 파싱 |
| `Person.java` | Gson 변환용 POJO |
| `person.json`, `people.json` | 파일 읽기 샘플 데이터 |
