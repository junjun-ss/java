# 01 File Read / Write

파일 읽기, 파일 쓰기, 라인 파싱 문제가 나오면 이 폴더를 봅니다.

| 파일 | 용도 |
| --- | --- |
| `FileReadWriteExample.java` | 텍스트 파일을 라인 단위로 읽고 다시 쓰는 기본 예제 |
| `FileMonitorExample.java` | 파일 변경 시간을 polling해서 변경 감지 |
| `input.txt` | 읽기 샘플 데이터 |
| `output.txt` | 쓰기 샘플 대상 |

가장 먼저 볼 파일: `FileReadWriteExample.java`
