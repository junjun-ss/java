# 03 HTTP URLConnection

외부 라이브러리 없이 Java 기본 HTTP 통신 문제가 나오면 이 폴더를 봅니다.

| 파일 | 용도 |
| --- | --- |
| `MessageProducer.java` | `HttpURLConnection` POST 예제 |
| `MessageConsumer.java` | `HttpURLConnection` GET 예제 |
| `HttpPolling.java` | 주기적으로 URL을 polling |

가장 먼저 볼 파일: `MessageProducer.java`, `MessageConsumer.java`
