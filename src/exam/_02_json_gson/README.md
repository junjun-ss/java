# 02 JSON / Gson

JSON 문자열, JSON 파일, POJO 변환 문제가 나오면 이 폴더를 봅니다.

가장 중요한 시험용 JSON 예제는 `src/main_exam/json`에 따로 분리되어 있습니다.

| 파일 | 용도 |
| --- | --- |
| `GsonCastingExample.java` | String, JsonObject, POJO, List, JSON 파일 변환 |
| `Person.java` | Gson 변환용 샘플 POJO |
| `person.json` | JSON 파일 읽기 샘플 |

가장 먼저 볼 파일: `GsonCastingExample.java`
