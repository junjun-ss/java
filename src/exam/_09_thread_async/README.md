# 09 Thread / Async

Thread, Runnable, CompletableFuture, pipe 문제가 나오면 이 폴더를 봅니다.

| 파일 | 용도 |
| --- | --- |
| `MyThread.java` | `Thread extends` 기본 예제 |
| `MyAsync.java` | `CompletableFuture.runAsync` 간단 예제 |
| `CompletableFutureExample.java` | executor를 직접 지정하는 비동기 예제 |
| `ThreadPipeExample.java` | `PipedInputStream`, `PipedOutputStream` 예제 |
| `ThreadLogic.java` | thread class 직접 생성 예제 |

가장 먼저 볼 파일: `CompletableFutureExample.java`
